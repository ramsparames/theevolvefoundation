# The Evolve Foundation — V2 Full-Site Redesign

This build is a redesign of the production website using the approved Homepage V2 prototype as the design and experience reference.

The production file architecture, page URLs, assets, JavaScript flows and Compass IDs are retained where functional behaviour depends on them. The HTML presentation layer has been re-authored so pages are not the old production layouts with V2 CSS patched on top.

Design reference: the approved Homepage V2 prototype.

Production untouched: this is a separate review build.
